Multi-Factor Risk Classifier & Governance Routing

Solves the Blind Automation Dilemma by quantifying operational blast radius into a bounded 0–100 score. Separates safe zero-touch auto-remediations from high-risk mutations that mandate human approval.

Mathematical Formulation
Risk Score = min(100, Score_Env + Score_Topology + Score_Action + Score_Confidence)
1. Environment (40% Wt)

Prod (+45) • Staging (+20) • Dev (+5) • Untagged (+25)

2. Topology (30% Wt)

Behind ALB (+35) • Disk Mounts (+25) • Standalone (0)

3. Action (20% Wt)

Delete (+20) • Stop (+15) • Release IP (+5)

4. Confidence (10% Wt)

Boundary CPU (+10) • Definitive 0-IOPS (-5)
